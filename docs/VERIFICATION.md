# Проверка релиза

Срез: 15 октября 2026. Это перечень выполненных проверок, а не обещание
одинакового результата на любом компьютере или постоянного доступа к Авито.

## Что проверено

| Проверка | Результат |
| --- | --- |
| Python tests | 29 проверок прошли: установка, пустой профиль, каталог, feedback, HTML, браузерные ограничения |
| Установка skill в пустой проект | Скопирован целый skill; из установленной копии работают `init`, `list`, `profile` |
| Существующий skill | Отличающиеся файлы не перезаписываются; выход через symlink отклоняется |
| Каталог | Номера с 1, повторный импорт сохраняет отказ, feedback обновляет HTML |
| Фото и HTML | Выход за разрешённую папку и symlink escape отклоняются; HTML-текст экранируется |
| Браузерный runtime | С нуля скачан закреплённый публичный commit, production-зависимости и Chromium; собран только browse |
| Повторный setup | CLI и patched manager сверены с сохранёнными SHA-256; повторная установка не потребовалась |
| Видимый браузер | На macOS запущен отдельный headed Chromium; локальная gallery, text, snapshot и screenshot отработали |
| Авито | Доступ остановлен на CAPTCHA; обход не выполнялся |
| Skill manifest | Официальный `quick_validate.py` принял SKILL.md |
| Секреты | Gitleaks 8.30.1 не обнаружил утечек в подготовленном пакете |

Среда выполненных запусков: macOS 27.0.1 / arm64, Python 3.14.6, Bun 1.3.14.
Тесты используют временные папки и вымышленные объявления. Связка
`capture → batch.json → import` проверяет реальный импорт сохранённых путей,
но не заменяет захват настоящего объявления Авито. Для capture требуется
селектор одного текущего фото; при смене миниатюры helper ждёт загрузки и
нового currentSrc. Длительность wait и прокруток ограничена.
На локальной тестовой странице Chromium helper дождался отложенной смены фото,
отклонил неоднозначный селектор и остановился при неизменившемся источнике.
Снимок выбранного элемента сохранён и визуально просмотрен.
Обычные команды при отсутствии daemon не запускают браузер сами.

## Что не подтверждено

- Полный живой поиск, проверка реальных объявлений и capture на Авито:
  тестовая сессия дошла до CAPTCHA. Пользователь проходит её вручную.
- Запуск внутри отдельных приложений OpenCode и Antigravity: проверен
  официальный формат discovery, но их полноценные сессии здесь не запускались.
- Linux, WSL2 и нативный Windows. В коде нет личных абсолютных путей,
  но переносимость кода не заменяет запуск на каждой системе.
- Совпадение размеров, наличие у продавца и качество любой будущей находки.

Браузер зависит от локального окружения, сети и текущего DOM Авито.
Отсутствующие поля или защита сайта требуют ручного разбора, а не догадки.
Пакет не использует авторскую AI Wiki, каталог, preferences, cookies или ключи.
Модель и разрешения предоставляет выбранный пользователем агент.

## Повторить локальные проверки

```sh
python3 -m unittest discover -s tests -v
```

Чистую установку браузера можно отдельно повторить по
[browser.md](../skills/avito-search/references/browser.md). Это скачивание
зависимостей и запуск локального ПО, а не платный API-вызов.

## English summary

The local test suite, a fresh skill install, a fresh pinned browser build,
headed Chromium and local gallery inspection were checked on macOS.
Gitleaks found no secrets in the release candidate. A live Avito session
stopped at CAPTCHA; real search and gallery capture remain unverified.
OpenCode/Antigravity discovery follows their official documentation, but
their complete sessions and non-macOS platforms were not run here.
