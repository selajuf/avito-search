# Avito Search

**Находи вещи на Авито по своему запросу. Сохраняй удачные находки и больше не смотри отклонённые.**

[English](README.en.md) · [Установка для агента](INSTALL.md) · [Как устроен браузер](skills/avito-search/references/browser.md)

Skill для Codex, OpenCode и Antigravity: агент смотрит объявления в видимом
браузере, проверяет фотографии и собирает локальную HTML-подборку.
В следующем поиске он учитывает сохранённые критерии и твои отказы.

## Что он делает

- Ищет по описанию или фотографиям, которые ты дашь.
- Переходит от рекомендаций к целевому поиску, когда в ленте нет подходящего.
- Сравнивает фото, цену, размер, материал, состояние и доступность.
- Даёт вещам постоянные номера и сохраняет обратную связь.
- Собирает страницу с крупными фотографиями, фактами и ссылками на объявления.

Поиск выполняет твой агент. Это не самостоятельный бот и не официальный API
Авито. Браузер, база и галереи работают на твоём компьютере; выбранная модель
работает по правилам твоей среды.

## Самый простой способ

Скопируй в своего агента:

> Установи skill Avito Search из https://github.com/selajuf/avito-search в этот проект. Прочитай INSTALL.md, проверь зависимости и подготовь видимый браузер. Не меняй глобальные настройки и не импортируй cookies из других профилей. Затем спроси, какие вещи я хочу найти.

Пакет начинает с пустого профиля. В нём нет авторских находок, размеров,
предпочтений, ключей или подключения к AI Wiki. Отдельный API-ключ для этого
skill не нужен; нужен работающий агент с выбранной моделью.

## Установка вручную

Нужны Python 3.10+, Git, Bun и графический рабочий стол. Рекомендуется
актуальная стабильная Bun; точные требования и закреплённая версия gstack
указаны в [инструкции браузера](skills/avito-search/references/browser.md).

```sh
git clone https://github.com/selajuf/avito-search.git
cd avito-search
python3 install.py --project ../my-avito
cd ../my-avito
python3 .agents/skills/avito-search/scripts/setup_browser.py
```

Открой `my-avito` в агенте и напиши:

> Используй avito-search. Хочу найти одежду по этим фотографиям. Сначала уточни, что важно для поиска, затем собери подборку.

Установщик копирует весь skill в `.agents/skills/avito-search`, включая
помощники. Подготовка браузера отдельно скачивает закреплённый gstack/browse
и Chromium. Глобальный gstack, hooks и разрешения агента не меняются.
Для Claude Code: `python3 install.py --project ../my-avito --host claude`.

## Данные остаются у тебя

По умолчанию всё хранится в `.avito-search/` рабочего проекта:

```text
.avito-search/
├── preferences.json       твои критерии
├── data/catalog.sqlite    объявления и решения
├── media/                 фотографии и референсы
├── galleries/             HTML-подборки
├── browser/               отдельный профиль и состояние браузера
└── runtime/               код браузера и Chromium
```

Для постоянного хранилища в другой папке задай `AVITO_HOME`. Не добавляй
эту папку в Git. Галерея может содержать твои заметки и фотографии:
она не публикуется автоматически.

«Учится» здесь означает сохранение твоего профиля и решений, а не обучение
новой модели. Можно менять критерии и начинать новые подборки.

## Важные ограничения

При CAPTCHA агент останавливается, чтобы ты прошёл её в видимой вкладке.
Skill не обещает обход защиты или постоянную доступность Авито. DOM сайта
может измениться; примерку, подлинность и наличие у продавца нельзя доказать
одной фотографией.

Структура skill подходит для современных Codex, OpenCode и Antigravity.
Фактические проверки конкретных систем перечислены в [проверке релиза](docs/VERIFICATION.md).
Windows пока рассматривается через WSL2 с графическим окружением;
нативная работа не заявляется.

Без отдельного поручения агент не пишет продавцам, не оформляет заказ,
не меняет VPN и не импортирует существующие сессии.
